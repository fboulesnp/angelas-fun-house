# Asset, source and license ledger

Everything visual and audible in the game is generated by code in this repository at
runtime. No images, models, audio files or video were downloaded, generated by an external
image service, or copied from the textbook.

| Asset | Where | Origin | License |
|---|---|---|---|
| All 3D models (cabinet, mechanisms, mansion, 29 attraction sets, room vignettes) | `src/game/render3d/*`, `src/app/scene/*`, `src/tables/*` | Procedural geometry written for this project | Project-original |
| Textures (wood grain, brushed metal, shingles, boardwalk, noise, labels, playfield prints) | `src/game/render3d/textures.ts`, `src/game/render/art.ts`, table painters | Generated on canvases at runtime | Project-original |
| Reflection environment | `Stage.setEnvironment` | Procedural studio scene → PMREM | Project-original |
| Characters (Angela, Pip, Professor Quark) | `src/app/components/Characters.tsx` | Original inline SVG, no real-person likeness | Project-original |
| Icons | `src/game/render/icons.ts` | Procedural canvas drawings | Project-original |
| Music and sound effects | `src/game/audio/audio.ts` | Web Audio synthesis of original motifs | Project-original |

## Curriculum sources

- *Bring Science Alive! 7th Grade Integrated, Student Edition* (524-page PDF) defines scope.
  It is reference material only: it is not shipped, not in version control (`.gitignore`
  blocks `*.pdf` and bulk extracted text), and no long passages, scans or textbook
  assessments are reproduced. Questions, explanations and glossary definitions are original.
- External sources used to verify or correct textbook claims are recorded per question
  (`evidence[]` with title, publisher, URL, access date, supported claim) and per lesson in
  `docs/content-review/Lnn.md`.
